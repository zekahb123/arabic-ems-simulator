# المحاكي الإسعافي العربي — مشروع Android 0.3.0

هذا مشروع Android Studio أولي يغلّف النموذج التدريبي المحلي داخل WebView. يعمل المحتوى الأساسي دون اتصال بالإنترنت، ولا يطلب أذونات حساسة.

## المحتوى الحالي
- واجهة عربية RTL ومصطلحات طبية عربية/إنجليزية.
- سيناريو إصابة مرورية تدريبي أولي.
- مشهد بصري تفاعلي مبسط لفحص عناصر مكان الحادث.
- أسئلة وتغذية راجعة ونتيجة تدريبية.

## متطلبات البناء
- Android Studio حديث يدعم Android Gradle Plugin 8.7.3.
- JDK 17.
- Android SDK Platform 35 وBuild Tools المناسبة.
- اتصال بالإنترنت أول مرة لتنزيل Gradle/Android Gradle Plugin ومكونات SDK إن لم تكن مثبتة.

## بناء APK تجريبي
1. فك ضغط مجلد المشروع وافتح مجلد `arabic_ems_android` في Android Studio.
2. انتظر Gradle Sync وثبّت أي SDK يطلبه Android Studio.
3. من القائمة: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. سيظهر APK التجريبي عادة داخل `app/build/outputs/apk/debug/app-debug.apk`.
5. انقل الملف إلى هاتف Android، واسمح بالتثبيت من هذا المصدر إذا طلب النظام ذلك.

## تنبيه مهم
هذه نسخة تعليمية أولية وليست منتجًا طبيًا معتمدًا. المشهد ليس محاكاة Unity ثلاثية الأبعاد؛ هو رسم ويب تفاعلي مبسط. يجب مراجعة المحتوى السريري من مختصين وتطابقه مع البروتوكولات المحلية قبل استخدامه في التدريب الرسمي. لم يُبنَ APK داخل بيئة إعداد هذه الحزمة لعدم توفر Android SDK/Gradle هنا.

## بناء APK عبر GitHub Actions (عند عدم توفر Android SDK محليًا)
1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد.
2. افتح تبويب **Actions** وفعّل Actions إذا طُلب ذلك.
3. اختر **Build Arabic EMS Simulator APK** ثم **Run workflow**.
4. بعد نجاح التشغيل، افتح صفحة التشغيل الناجح ونزّل ملف **arabic-ems-simulator-debug-apk** من قسم **Artifacts**.
5. فك ضغط ملف Artifacts؛ ستجد `app-debug.apk` بداخله.

يتطلب هذا المسار حساب GitHub وإجراء الرفع والضغط على Run workflow يدويًا؛ لا يمكنني تنفيذ هذه الخطوات داخل حسابك من هنا. ملف APK غير مضمّن في هذه الحزمة لأن بيئة الإنشاء الحالية لا تحتوي Android SDK/Gradle ولا تستطيع الوصول إلى الإنترنت لتنزيلهما.
